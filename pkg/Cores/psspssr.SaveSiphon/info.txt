SaveSiphon - cartridge backup for GB, GBC and GBA

Insert a cartridge with the Pocket powered off, power on and launch
SaveSiphon. Choose Back up save, Back up ROM or Back up save + ROM.
Files go to /Assets/savesiphon/common/ and are never overwritten
(a second backup gets _1, _2, ...).

GBA saves: SRAM, Flash 64K/128K, EEPROM 512B/8K. GB/GBC: MBC1/2/3/5 RAM.
Read-only: cartridge save data is never written. Commands needed to
read some carts (Flash bank select, EEPROM read requests, GB mapper
banking) are confirmed first, and a hardware write guard blocks
anything else. Every read is done twice and verified.

Power off before swapping cartridges.
